# Academic Portfolio

This repository is the Markdown source dossier for the academic, research,
leadership, international, and professional portfolio of Cecilia Lis Costa.

The initial use case is a master's application in quantum technologies, but the
material is structured so it can also support future graduate, research,
fellowship, and professional applications.

## Repository Map

- `docs/` - shared context, timeline, evidence index, skills matrix, and name
  clarification note.
- `reports/` - evidence-backed experience reports organized by area.
- `sources/` - normalized local copies of evidence files and source records.
- `outputs/` - destination folders for later CV, application portfolio, and full
  dossier exports.

## Evidence Policy

Use Cecilia Lis Costa as the current name throughout portfolio prose. Some
historical documents may use a former legal name or older pronouns; those records
refer to the same individual and should be handled through the clarification note
in `docs/04_name_clarification_note.md`.

Reports should distinguish:

- facts confirmed by local source files;
- public references that still need archiving or formal citation capture;
- inferred context that should not be treated as official evidence.
