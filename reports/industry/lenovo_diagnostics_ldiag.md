# Lenovo Diagnostics / LDiag

Status: draft  
Last updated: 2026-07-04

## Summary

Cecilia Lis Costa worked as a software developer on Lenovo Diagnostics / LDiag,
an industrial research and development project connected to Lenovo and the
Federal University of Ceara.

The project involved hardware diagnostics, automated validation, diagnostic test
implementation, and maintenance of software supporting Lenovo computer systems.

## Project Context

Working records identify the project as a university-industry R&D initiative
under Brazil's Information Technology Law. The current local overview records:

- project/product: Lenovo Diagnostics / LDiag;
- laboratory: LSBD, Laboratory of Database and Software Engineering;
- administrative management: FCPC;
- industrial partner: Lenovo;
- coordinator: Prof. Dr. Javam de Castro Machado;
- FCPC project registration in 2014: `CV LENOVO`, `GPF 3059`, `LDIAG FASE III`;
- approved budget in 2014: R$ 2,668,561.99.

These official registration details still need the original FCPC report file in
the repository.

## Technical Scope

The source overview describes diagnostic modules and validation work involving:

- graphics processing units and video cards;
- persistent storage devices, including IDE/SATA hard drives, NVMe, and eMMC;
- RAID;
- cameras;
- batteries;
- diagnostic routines and automated validation;
- bug investigation, reproduction, and fixes;
- C++ development.

## My Role and Contributions

I worked as a software developer contributing to the research, implementation,
and maintenance of hardware diagnostics and validation tests.

My responsibilities included:

- developing diagnostic and validation tests for hardware components;
- implementing C++ diagnostic routines;
- investigating, reproducing, and fixing defects;
- maintaining compatibility across hardware platforms;
- supporting continuous improvement of the diagnostics platform;
- communicating with Lenovo partners on technical requirements, status, and
  issue resolution.
