# Game Awards and Recognitions

Status: draft  
Last updated: 2026-07-04

## Summary

Current source notes identify competitive funding selections and festival
recognitions for two educational game projects: Carcara - Asas da Justica and
Vetor.

Until individual contribution evidence is added, these should be described as
project or team recognitions rather than individual awards.

## Recognitions

### Carcara - Asas da Justica

Recognition: selected for competitive federal funding  
Program: INOVApps Program  
Institution: Brazilian Ministry of Communications  
Year: 2014

The source note describes Carcara - Asas da Justica as an educational serious
game designed to teach Brazilian Consumer Protection Law through interactive
storytelling and gameplay. The project was competitively selected through the
INOVApps Program, a nationwide initiative supporting innovation in mobile
applications and digital games.

References listed in the source note:

- UOL: `https://www.uol.com.br/start/ultimas-noticias/2015/05/29/jogo-nacional-gratis-sobre-advogados-diverte-e-ensina-direito-do-consumidor.htm`
- Baguete: `https://www.baguete.com.br/noticias/apps-recebem-ate-r-100-mil-do-minicom`
- Supernova Games: `https://supernova.games/carcara-br/`

### Vetor

Recognition: selected for competitive federal funding  
Program: INOVApps Program  
Institution: Brazilian Ministry of Communications  
Year: 2015

The source note describes Vetor as an educational digital game selected through
the 2015 INOVApps Program. Supporting documentation is noted as available from
personal project records, but no primary record has been added to the repository
yet.

### Vetor - BIG Starter

Recognition: winner  
Award: Best Educational Game Project  
Competition: BIG Starter, Brazil's Independent Games Festival  
Year: 2016

The source note states that Vetor won the Best Educational Game Project award at
BIG Starter, part of the BIG Festival.

References listed in the source note:

- BIG Festival winners page: `https://latam.gamescom.global/en/winners/`
- UOL: `https://www.uol.com.br/start/ultimas-noticias/2016/07/01/horizon-chase-e-eleito-melhor-jogo-do-big-festival-2016.htm`

Recognition: finalist  
Category: Best Educational or Social Impact Game  
Competition: Brazil's Independent Games Festival
