# Traffic Monitoring in Video Sequences

Status: draft  
Last updated: 2026-07-04

## Summary

Cecilia Lis Costa participated in the Traffic Monitoring in Video Sequences
research project at the Federal University of Ceara from 2014-03-25 to
2014-06-20.

The project applied computer vision and image processing techniques to traffic
video analysis.

## Project Context

The work was connected to research on automated traffic monitoring using video
sequences. The project combined computing and transportation-engineering
interests, with emphasis on extracting and analyzing visual structures from image
sequences.

## My Role and Contributions

I participated as an undergraduate software developer. My work focused on
software implementation for computer vision methods applied to traffic video.

Responsibilities included:

- software development in C and C++;
- implementation of computer vision and image processing routines;
- extraction and analysis of structures from image sequences;
- support for research prototypes and experimental validation;
- collaboration with researchers working on traffic monitoring and video
  analysis.

## Skills Demonstrated

- Computer vision
- Digital image processing
- C and C++ programming
- Scientific software development
- Research prototype implementation
- Multidisciplinary collaboration
